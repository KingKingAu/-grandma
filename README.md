This repository contains a Godot project, if you would like to open it just open it via Godot. (Made in Godot 4.7.2stable Steam)
If you would like to play it, here is a web link: https://kau22.itch.io/splitsecond

Controls:
WASD to move and Left Shift to rewind for Player 1
Arrow Keys to move and Right Shift to rewind for Player 2

AIM:
Go as far as you can to beat the other player within the time limit. Use to rewind to save yourself, if you are too late you DIE and the timer reduces to 5 seconds (also your points divide by 1.5)


.


About the Development~

This game was made in Godot, written in GDScript. The most difficult part of the game in my opinion was creating the procedurally generating levels and I'm quite happy with how that turned out (along with the seed system). I see now that I could've use Godot's viewport system for the two different player screens, but oh well I guess too late now :D

Also the rewind mechanic too quite a few attempts to fix because for some reason a few times it would get stuck when it fully rewinded? So then I had to make it so that you cannot start rewinding unless there is already a minimum number of items stored in the list of frames.
