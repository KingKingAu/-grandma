This repository contains a Godot project, if you would like to open it just open it via Godot. (Made in Godot 4.7.2stable Steam)
If you would like to play it, here is a web link: https://kau22.itch.io/splitsecond

Controls:
WASD to move and Left Shift to rewind for Player 1
Arrow Keys to move and Right Shift to rewind for Player 2

AIM:
Go as far as you can to beat the other player within the time limit. Use to rewind to save yourself, if you are too late you DIE and the timer reduces to 5 seconds (also your points divide by 1.5)
